# Decision Slides

Create or review restrained, reader-first business presentations in HTML, PPTX, or Google Slides: one message per slide, a decision section separated from a complete appendix record, intentional line breaks, exclusive Japanese–English switching, and layout-stable PDF export. The main skill is [`SKILL.md`](SKILL.md).

HTML・PPTX・Google Slides で、初見の読み手が理解できる意思決定用のプレゼン資料を作成・レビューするためのスキルです。1スライド1メッセージ、本編と付録の分離、意図した改行、日英の排他切り替え、崩れないPDF書き出しを扱います。本体はリポジトリ直下の[`SKILL.md`](SKILL.md)です。
